This is a powerful yet easy-to-use tool that helps **detect diabetic retinopathy** — a serious eye condition that can lead to blindness if untreated. The software analyzes eye images and tells you the severity level, helping doctors and patients catch problems early.

Think of it as a smart assistant that looks at eye photos and says: "This looks healthy" or "This needs urgent attention."

## 🛠️ Troubleshooting

Having trouble? Here are common fixes:

### ❌ Program Won't Start

- Make sure you have **Python installed** (free download from python.org)
- Ask a friend who knows computers to check if you have all required components — the included "requirements.txt" file lists everything

### 🖼️ Image Won't Upload

- Use JPG or PNG format only (not HEIC or BMP)
- Keep image size under 10 MB
- Make sure the image shows the back of the eye clearly

### 🐢 Program Runs Slowly

- Close other heavy programs (games, video editors)
- Give the program a minute to load — AI models take time to start
- Use a smaller image for faster results
